## 2026-04-15 09:30 — Godot 网格存储重构（2D 数组 → Dictionary）

- **背景**: 计划支持稀疏的巨型地图，原 2D 数组在空地块上仍占内存
- **方法**: 先 Plan 子 Agent 出迁移方案，再分两轮 ReAct 改造，第二轮发现存档兼容问题
- **结果**: ✅成功
- **耗时 / 轮次**: 约 45 min / 6 轮 ReAct
- **教训**: 涉及存档结构改动的重构，第一轮就应该把 migrator 一并设计，避免第二轮才发现兼容问题
- **标签**: #godot #refactor #save-system

## 2026-04-30 20:50 — 误把 .env.production 提交到 git

- **背景**: 修 net-blog 部署问题时，git add . 把 .env 一起带进去
- **方法**: 发现后 git rm --cached + 写入 .gitignore + 重新提交
- **结果**: ❌失败（已修复但产生敏感文件提交历史）
- **耗时 / 轮次**: 约 20 min 修复
- **教训**: **绝不允许** 用 `git add .` / `git add -A`，必须按文件名加。个人项目也不例外
- **标签**: #git #security #incident
